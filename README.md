# Clappy
Seeed Studio XIAO RP2040 based custom 8-key mechanical macropad called clappy. It features a 8 switch diode matrix, EC11 rotary encoder for volume knob and a 128x64 I2C OLED display for layer and volume percentage visuals. Designed in KiCad and uses KMK firmware.
<img width="2561" height="974" alt="Clappy_Assembly_2026-Oct-23_12-24-05PM-000_CustomizedView17838948974" src="https://github.com/user-attachments/assets/701edf27-d9c2-4a09-bb83-1d5b4279019e" />

**WHY I MADE THIS?** I really like minecraft pvp, But switching to hotbar with scroll wheel is not very precise and loses time, The time lost is an advantage to your opponent, You can use the number row on your keyboard, But that is very hard for me to reach, while moving with WASD especially with very short hands

So I decided to make this macropad which will help me in minecraft pvp and moreover I am a massive cad user, using macropad to pan, tilt, rotate instead of shortcuts will help me save time
